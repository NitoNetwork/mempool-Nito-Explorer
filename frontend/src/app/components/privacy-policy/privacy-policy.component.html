Privacy


Nito Mempool Explorer is public, read-only blockchain software. Blockchain transactions, addresses, nullifiers, block data, and public transaction-envelope fields are public network data. Do not treat a lookup as private.

Wallet data

The explorer does not need and must never receive a seed phrase, spending key, full viewing key, wallet file, RPC cookie, or wallet RPC credential. Bech32x receivers and decrypted Orchard notes remain wallet-side data.

Browser storage

The default interface uses local browser storage for display preferences such as theme, amount unit, and time zone. The qualified public build does not enable accounts, advertising, third-party analytics, fiat price feeds, or transaction-acceleration services.

Server logs

This source repository does not define the retention policy of a deployed website. An operator may receive IP addresses and request metadata through its reverse proxy or hosting provider. Public operators must publish their own accurate logging, analytics, cookie, and retention policy.

Self-hosting

Self-hosting can reduce reliance on a third-party explorer, but it does not make public blockchain queries private by itself. Protect Nito Core RPC, ElectrumX administrative RPC, MariaDB, and TLS keys from public access.

Repository security guidance is available in SECURITY.md.
